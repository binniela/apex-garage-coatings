# Apex Garage Coatings

Marketing and quote-request site for a polyaspartic garage floor coating company (Next.js 14).

Live: https://www.epoxycoatingco.com

## Develop
    cp .env.example .env.local   # fill in values
    npm install
    npm run dev

## Deploy
Deployed to Vercel project `apex-garage-coatings` (via `vercel deploy --prod` or Git push once a repo is connected).
